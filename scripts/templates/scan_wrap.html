SET Downtrend Scanner

หุ้นที่กำลังอยู่ในขาลงตอนนี้

วัดจาก ราคาสูงสุดนับตั้งแต่จุด peak/trough ที่ยืนยันล่าสุดของแต่ละหุ้น เทียบกับราคาล่าสุด (ครอบคลุมทั้งกรณีที่จุดยืนยันล่าสุดเป็น peak หรือ trough) เฉพาะหุ้นที่มีการซื้อขายล่าสุดในช่วง 60 วันที่ผ่านมา เรียงจากลดลงมากสุดไปน้อยสุด — คลิกแถวเพื่อดูรายละเอียด cycle ของหุ้นนั้น

Tickerวันที่ล่าสุดที่เป็นจุดสูงสุดราคาสูงสุดนั้นราคาล่าสุด% จากจุดสูงสุดจำนวนวัน
ข้อควรระวัง: นี่คือการระบุ pattern ราคาที่ผ่านมาแล้ว ไม่ใช่การพยากรณ์ทิศทางในอนาคต หุ้นที่ "ลง" ต่อไปอาจจะลงต่อ หรือกลับตัวขึ้นก็ได้ ไม่ใช่คำแนะนำให้ซื้อ/ขาย ใช้เพื่อการศึกษาเบื้องต้นเท่านั้น
